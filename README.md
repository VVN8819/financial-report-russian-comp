# financial-report-russian-comp
Учебный проект, демонстрирующий:
- Обработку данных "Финансовая отчётность российских компаний" (https://github.com/irlcode/RFSD),
- Поиск, загрузку, чтение и сохранение файлов за нужный год ('HfFileSystem', 'hf_hub_download', 'pathlib'),
- Переименование колонок через словарь (https://raw.githubusercontent.com/irlcode/RFSD/main/aux_data/descriptive_names_dict.csv),
- Исследовательский анализ EDA с последующей очисткой, фильтрацией строк, проверкой на дубли, заполнением медианой остатков и сохранением очищенного csv файла ('.drop', '.notna', '.duplicated', '.fillna(median_val)').
- Описательную статистику с визуализацией через гистораммы ('.hist') их сохранение в струтуре

# Структура репозитория
financial-report-russian-comp/

1. scripts/ - датасеты и исходные коды Python

    - data/ - Сырые и обработанные датасеты

        - rfsd_sample.csv - Сырые данные по финансовым отчетам компаний РФ

        - rfsd_sample_clean.csv - Очищенные и отфильтрованные данные по финансовым отчетам компаний РФ

    - reports/ - Сохраненные графики анализа в .png

    - init.py - RFSD Analysis Scripts Package

    - eda.py - Исследовательский анализ EDA, Описательная статистика

    - preprocess.py - Очистка, фильтрация строк, проверка на дубли, заполнение медианой остатков и сохранение очищенного csv файла

    - rfsd_loader.py - Поиск, загрузка, чтение, переименование колонок и сохранение файлов за нужный год

    - visualization.py - Визуализация через гистораммы с применением логарифмической шкалы и их сохранение
    
2. .gitignore - Правила исключения для Python-проектов

3. LICENSE - Лицензия использования

4. README.md - Документация проекта

5. run_pipeline.py - вызывает rfsd_loader.py, preprocess.py, eda.py, visualization.py

# Описание ключевых файлов
- scripts/rfsd_loader.py - Демонстрация поиска, загрузки, чтения, переименования и сохранения файлов за нужный год ('HfFileSystem', 'hf_hub_download', 'pathlib'). Вычленяет данные за определенный год с ограниченным количеством строк и колонок.

- scripts/eda.py - Реализация исследовательского анализа EDA. Выявляет пропущенные значения с помощью '.isnull' и считает их количество через '.mean'. Отображение описательной статистики.

- scripts/visualization.py - Демонстрация результатов очищенных и отфильтрованных данных по финансовым отчетам компаний РФ через постороение гистораммы (.hist) библиотеки 'matplotlib"
  
- .gitignore - Исключает папку .venv/ и другие.

- rfsd_sample.csv - Хранилище сырых данных по финансовым отчетам компаний РФ за определенный год с ограниченным количеством строк и колонок.

- rfsd_sample_clean.csv - Хранилище очищенных и отфильтрованных данных по финансовым отчетам компаний РФ за определенный год с ограниченным количеством строк и колонок.
